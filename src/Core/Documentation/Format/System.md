# System-defined Alphabet

This document defines the system-defined alphabets used by the conversion system.

---

## Overview

The conversion system provides predefined shuffled alphabets through from() and to().

Available system-defined bases:

- Base10
- Base32
- Base58
- Base62
- Base64
- Base100

---

## Base10

Base10 represents indexed values derived from Base100.

Range:

- 00 → 99

Used for structured numeric input and output.

---

## Base100

Base100 defines a restricted 100-character alphabet without whitespace.

```text
0987654321abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ!"#$%&'()*+,-./:;\=´?@[]^_`{|}~£§¨²³µ°
```

Used as a normalized input domain.

---

## Base256

Base256 accepts raw byte input, including whitespace.

Input is normalized to Base100 before conversion.

External or arbitrary encoded input from Base100 and Base10 to Base256 that does not satisfy the normalization contract will be rejected and return null.

→ See: [Normalization.md](/src/Core/Documentation/Pipline/Normalization.md)

---

## Base32, 58, 62 and 64

These bases define encoded output formats provided by the conversion pipeline.

Only values generated by this repository are guaranteed to decode correctly.

External or arbitrary encoded input that does not satisfy the normalization contract will be rejected and return null.
